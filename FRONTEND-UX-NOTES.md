# CustomerVault front-end UX refresh

This refresh is presentation-focused. It retains the existing HTML structure, JavaScript behaviors, API routes, and database logic while improving visual hierarchy, spacing, responsive layout, keyboard focus visibility, table readability, hover feedback, and reduced-motion accessibility.

## Run locally
1. Install Python dependencies: `pip install -r requirements.txt`
2. Copy `config_local.example.py` to `config_local.py` and enter your local MySQL credentials.
3. Start the server with `python app.py` and open `http://localhost:8000`.

The archive intentionally excludes local credentials and Python bytecode caches. Keep your own `config_local.py` private.
